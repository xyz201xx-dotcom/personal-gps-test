# いまここ精度

走行中の現在地とGPSの推定精度を大きく表示するシンプルなWebアプリです。位置情報を連続監視し、推定誤差が100 mを超える粗い測位は地名・座標として採用しません。

## 起動

位置情報APIは `localhost` またはHTTPSでのみ動作します。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、「計測をはじめる」を押してください。

## データ

- 座標・推定精度: ブラウザの Geolocation API
- 地名: 国土地理院の逆ジオコーダーおよび市区町村データ

端末が返す精度値は、取得した座標を中心とするおおよその誤差半径（メートル）です。

## 精度を上げるために

- 端末の位置情報の許可を「正確な位置情報」にする（iPhone: 設定 → プライバシーとセキュリティ → 位置情報サービス → 使用中のブラウザ → 「正確な位置情報」をオン）。
- 屋外で空が広く見える場所に出て、取得開始後しばらく待つ。建物内、車内の奥、地下、ビル街ではGPSが大きくずれます。
- Wi-Fi・モバイル通信・端末の位置情報サービスをオンにする。GPS単独より初期位置の特定が速く安定する場合があります。

このアプリでは推定誤差が100 mを超える結果を「高精度の位置情報を待機中」として扱います。しきい値は `app.js` の `MAX_USABLE_ACCURACY_METERS` で変更できます。2 km程度のずれが続く場合は、端末側が「おおよその位置」を返しているか、GPSを受信できていない状態であり、Webサイトだけで正しい座標へ補正することはできません。

## 通信量の表示

画面の「このアプリの受信量（概算）」は、このページが地名検索のために取得したレスポンス本文の合計です。端末全体の通信量、GPSの補助測位通信、HTTPヘッダー、キャッシュ、送信分はブラウザの制限により取得できないため、契約上の実通信量とは一致しません。
