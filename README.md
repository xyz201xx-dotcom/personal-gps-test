# いまここ精度

走行中の現在地とGPSの推定精度を、5秒ごとに大きく表示するシンプルなWebアプリです。

## 起動

位置情報APIは `localhost` またはHTTPSでのみ動作します。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、「計測をはじめる」を押してください。

## データ

- 座標・推定精度: ブラウザの Geolocation API
- 地名: 国土地理院の逆ジオコーダーおよび市区町村データ

端末が返す精度値は、取得した座標を中心とするおおよその誤差半径（メートル）です。
